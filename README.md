# Остров для Windows 11

«Динамический остров» в верхней части экрана: музыка (Spotify, YouTube, Яндекс Музыка), громкость, яркость и раскладка, уведомления Telegram и почты с быстрым ответом, загрузки и копирование файлов, буфер обмена, стикеры с задачами и напоминаниями, полка для файлов.

## Установка

Скачайте `Island-Setup-…exe` из папки [`releases`](releases) и запустите. Установщик не просит прав администратора: остров ставится в `%LOCALAPPDATA%\Programs\Island`, появляется в «Пуске» и удаляется через «Параметры → Приложения». Дальше остров обновляется сам.

Без установки: скачайте архив `Island-….zip`, распакуйте и запустите `Island.exe`.

## Как устроены обновления

Остров раз в несколько часов читает [`latest.json`](latest.json). Если там версия новее установленной, он предлагает обновиться, скачивает архив по ссылке `url` и заменяет свои файлы.

Чтобы выпустить новую версию: положите архив (и установщик) в `releases/` и поменяйте `version`, `url` и `setup` в `latest.json`. Установленные копии подхватят её сами.

## Сборка

Tauri 2 (Rust + WebView2). Интерфейс лежит в `dist/`, код для Windows в `src-tauri/src/`.

```
cd src-tauri
cargo build --release --target x86_64-pc-windows-gnu
```

Установщик собирается NSIS из `installer/island.nsi`:

```
makensis -DVERSION=0.12.0 -DSRC=<папка с Island.exe> -DOUT=Island-Setup-0.12.0.exe installer/island.nsi
```
